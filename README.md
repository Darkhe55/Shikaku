# 数方 Shikaku

一个基于 Web 的数方（Shikaku）谜题游戏：原生 SVG 渲染、拖拽画矩形、实时校验、回溯求解、逻辑解题逐帧回放，内置唯一解题库与自定义题板。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5214/**（端口来自 `package.json` 的 `puzzle.port`）。

> 也可以 `npm run dev`（不自动打开浏览器），再访问 <http://127.0.0.1:5214/>。

## 游戏规则

- 把整个矩形棋盘划分成若干个小矩形；
- 每个小矩形**恰好包含一个数字**，且矩形的面积（格数）**等于该数字**；
- 每个格子恰好属于一个矩形，数字格不能被多个矩形共用；
- 每道题都有唯一解，且内置题都可以纯逻辑推完。

## 逻辑解题定式（规则引擎）

`src/game/solver.ts` 的候选传播与 `src/game/logic.ts` 的回放都只做可证明的推理，不猜；回溯搜索只作为兜底。
规则名会显示在逻辑解题回放的每一步理由里：

| 规则 | 说明 |
|------|------|
| R1 数字格唯一候选 | 某个数字只剩一个候选矩形（面积 = 数字、且只含该数字）→ 必然放它 |
| R2 覆盖传播 | 某个未覆盖格只剩一种候选矩形能覆盖 → 必然放它 |
| R3 候选排除（隐藏单值） | ① 某未覆盖格的所有候选都属于同一个数字 → 该数字必须覆盖这一格，排除该数字「不含此格」的候选；② 某数字的全部候选都覆盖同一格 → 别的数字不能再用这一格，排除别的数字「含此格」的候选 |
| R4 反证 | 优先从剩余候选最少的数字入手逐候选试放并传播，立刻矛盾 → 排除该候选 |
| R5 回溯试探 | 规则推不满（如自制难题）时用 MRV 回溯补完并标注；补完时把当前盘面已有的矩形（玩家放置 + R1–R4 已推出的）作为固定条件继续，不会拿空盘的另一组解来拼 |

安全条件：R1–R3 都是精确覆盖的单元传播 / 隐藏单值，结论与「题面存在解」无关地成立；
R4 仅在 R1–R3 已到不动点后试放，且试放分支不产生回放帧。候选传播同时用于求解器，
因此 `npm run check` 的唯一解搜索节点也大幅下降。

## 操作

| 操作 | 说明 |
|------|------|
| 左键拖拽 | 从矩形一角拖到对角，松开即画出矩形；覆盖到旧矩形时会替换它 |
| 左键单击矩形 | 取消（删除）该矩形 |
| 左键单击空格/数字 | 选中该格；从选中的数字格再拖拽即可画矩形 |
| 右键 | 删除点到的矩形 |
| 方向键 | 移动选中格（绘制中则调整矩形对角） |
| Enter | 开始 / 结束矩形 |
| Esc | 取消当前绘制或选中（不会清空盘面） |
| Delete / Backspace | 删除选中格所在的矩形 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / L / P | 检查 / 提示一格 / 显示解 / 逻辑解题 / 暂停回放 |
| R / M | 随机抽题 / 音效开关 |
| + / − / 0 | 放大 / 缩小 / 视图复位 |

## 校验与提示

- **实时校验**：未覆盖格、数字未被使用、矩形面积与数字不符、矩形含多个数字、矩形重叠、矩形越界都会即时高亮（红色虚线框 / 斜线 / 数字变红），状态栏给出文字说明；
- **提示一格**：优先删除一个与参考解不符的矩形，否则补上参考解里缺失的一个矩形；
- **显示解**：填入参考解（内置题）或求解器算出的可行解；
- **逻辑解题**：规则 1「数字格只剩一个候选矩形」、规则 2「覆盖传播：某个格子只剩一种矩形可选」、规则 3「候选排除（隐藏单值）」、规则 4「反证」逐帧回放，按 `P` 暂停/继续，回放结束盘面通常已解出。
- **从当前盘面继续**：逻辑解题以当前盘面已放矩形为固定条件继续推理（R5 回溯补完也用它们做种子），回放帧只追加新矩形、`from`/矩形 id 不会与玩家已有放置冲突，不会覆盖或删除玩家已放矩形。

## 自定义题板

- 点「自定义」打开编辑器：设置宽高（3×3 – **30×30**）→「生成网格」；
- 鼠标点击格子循环 `空 → 1 → … → 20`；键盘直接按 1–9，0.7 秒内继续按数字可输入 10–20（如 `1`、`2` → 12），方向键移动、`.` / 退格清空；
- 「保存到题库」时会自动用求解器检查：无解会拒绝保存，解不唯一会给出警告但允许保存，唯一解则提示「唯一解 ✓」；
- 已保存的自定义题可以「编辑」回填后覆盖保存；删除需要点两次（第一次变成「确认」）；
- 自定义题同样支持求解、逻辑解题、进度保存。

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录（`library.json` / `progress.json` / `last-puzzle.json`）；静态部署时自动降级到浏览器 localStorage。

## 命令

```bash
npm run dev       # 开发服务（端口 5214）
```

## 图片导入题库（识图 CLI）

```bash
npm run import-image -- month.png                # 识别并预览（不写入）
npm run import-image -- month.png --verify       # 额外求解 / 唯一性检查（大盘面会超时警告）
npm run import-image -- month.png --append       # 写入 src/game/imported-puzzles.ts
npm run import-image -- month.png --json out.json  # 导出识别结果
```

- 全自动识图：Playwright + 本机 Edge 取像素 → 网格交点大圆点定位格子与外框 →
  每格中心附近的深色数字（1–3 位）连通域提取（相邻数字粘连时按列墨迹自动切开）→
  字形聚类 + 多字体多字号模板匹配判读。
- 结构校验：数方的天然不变量「所有数字之和 = 格子总数」必须成立；不成立时拒绝写入，
  可用 `--map 簇号=数字` 覆盖字形簇判读或 `--fix "列,行=数字"` 修正个别格子。
- 导入题写入 `src/game/imported-puzzles.ts`，`npm run gen` 不会覆盖；游戏启动时会与内置题一起加载。
- 编码：沿用题库的 base36 单字符格式；出现 >35 的数字（真实大盘面常见）时自动改用
  逗号分隔的十进制格式（`src/game/types.ts` 的 `decodeClues` 两种都支持），
  所以 40×50、最大数字 204 这类题也能载入。
- 限制：`--verify` 对 40×50 大盘面通常会超时（只警告）；未带参考解时「显示解 / 提示一格」
  依赖求解器现场计算，大盘面可能很慢。

## 实现要点

- **状态模型**：盘面 = 矩形槽位数组，Move 为 `{ index: 矩形 id, from/to: 矩形几何编码 }`（`from = 0` 新建、`to = 0` 删除），撤销即交换 from/to，与模板的撤销/重做、逻辑回放天然兼容；
- **求解器**：先为每个数字枚举「面积 = 数字且只含该数字」的候选矩形，每个节点先做 R1–R3 候选传播，再用 MRV（剩余候选最少的未覆盖格 / 数字）+ 精确覆盖回溯；内置题与自定义题的唯一解检查都用它；
- **渲染**：矩形填色 + 粗边界 + 数字 + 错误高亮；拖拽预览直接更新 SVG 覆盖层，不整盘重绘，指针捕获不会中断；
- **题库生成**：随机矩形切分 → 每个矩形随机放一个数字 → 唯一解计数 = 1 → 逻辑推演必须饱和，才收进题库（`npm run gen` 可复现）。

## 尺寸与棋盘支持

| 项目 | 范围 / 说明 |
|------|------|
| 棋盘形状 | 矩形，宽高各自独立，**支持非正方形**；整盘必须被矩形铺满，没有盘外格 |
| 异形棋盘 | 不支持（规则要求把整个矩形棋盘切开，每个格子恰好属于一个矩形） |
| 内置题 | 5×5、6×6、7×7、8×8、9×9、10×10、12×12（8 题 / 7 种尺寸） |
| 自定义题板 | 3×3 – 30×30（本批从 20×20 提升）；线索值 1–30（0.7 秒内连按可键入两位数，如 3、0 → 30） |
| 编码上限 | 线索单字符 base36 最多 35，超过自动改用逗号十进制（识图导入可到 204）；矩形几何编码支持 ≤40 边长 |
| 识图导入 | 40×50 量级 |
| 旧数据兼容 | 题面 / 参考解 / 进度存档格式未变，旧题库完全兼容 |

> 本批改动：自定义题板 20×20 → 30×30，线索值上限 20 → 30。
